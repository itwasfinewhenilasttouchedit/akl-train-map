Auckland trains — proposed UX refresh

Static mockup of the proposal in PROPOSAL.md. Dark theme retained, AT line colours untouched, honesty vocabulary made systematic. Every interactive target here is at least 44×48 px; every colour pair was computed against WCAG 2.2 thresholds. Content is realistic fake data.

5. What this mockup deliberately does not change

AT’s four line colours (fixed by the operator, and all measured compliant) · the dark palette · hollow squares for out-of-service stock, with no destination or ETA · "Not sure" as a first-class carriage answer · the closed behaviour list with no free-text box · praise never rendering as a fault · resolved reports staying visible · the planner’s "we can’t tell you which set this will be until it’s running" sentence · anonymity, with no account and no stored identity · and the single-file, no-build architecture — every style above is a CSS custom property and plain CSS, implementable directly in web/index.html.
